共源级放大器

忽略沟道长度调制时，低频电压增益近似为 Av = −gmRD。详细推导可参考 小信号分析步骤。

分析步骤

  1. 确认晶体管工作在饱和区。
  2. 计算跨导 gm 与输出电阻 ro。
  3. 将独立直流源置零，求取端口等效阻抗。
参数典型值设计影响
过驱动电压200 mV影响跨导效率与摆幅
负载电阻10 kΩ决定增益与输出极点

计算示例

def intrinsic_gain(id_ma: float, vov: float, va: float) -> float:
    # gm = 2 * ID / VOV，ro = VA / ID
    return 2 * va / vov

gain = intrinsic_gain(0.5, 0.2, 20.0)
print(f"gm · ro = {gain:.1f}")

复习清单

  • 区分直流偏置与交流小信号。
  • 检查体效应是否不可忽略。
  • 记录公式的适用条件，而不只记录结论。

重点：增益提高并不意味着整体性能一定更好，还要同时检查带宽、噪声与功耗。
